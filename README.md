# Космические приключения — семейный квиз

Интерактивный квиз в стиле ИВИ: на телевизоре (большом экране) показываются вопросы,
игроки подключаются со своих телефонов по QR-коду и отвечают.

- **ТВ-экран:** главная (каталог ИВИ) → лобби с QR → вопросы → итоги с рекомендацией серии.
- **Телефон:** открывает `/join`, вводит имя и отвечает на вопросы.

## Стек

Только стандартная библиотека Python 3 (без внешних зависимостей). Встроенный HTTP-сервер
отдаёт статику (`index.html`, `join.html`, `assets/`) и держит одну игровую комнату в памяти
через эндпоинты `/api/*`. QR-код генерируется на сервере.

## Запуск локально

```bash
python3 server.py            # порт 8765 по умолчанию
python3 server.py 9000       # свой порт
```

- ТВ: `http://127.0.0.1:8765/`
- Телефон (в той же сети): адрес, который сервер печатает при старте (`.../join`).

## Деплой (Render)

Сервер с состоянием в памяти, поэтому нужен хостинг с постоянным процессом
(не serverless). В репозитории есть `render.yaml` (Blueprint):

1. На [render.com](https://render.com) → **New → Blueprint**.
2. Подключить этот GitHub-репозиторий — Render прочитает `render.yaml`.
3. Deploy. Render сам задаёт `PORT`, а публичный адрес прокидывает в
   `RENDER_EXTERNAL_URL` — на него и указывает QR-код для телефонов.

Переменные окружения:

- `PORT` — порт (подставляет хостинг).
- `PUBLIC_URL` / `RENDER_EXTERNAL_URL` — публичный адрес для QR-кода подключения.

> На бесплатном плане Render сервис «засыпает» при простое — первый запрос после паузы
> может открываться ~30–60 секунд.
